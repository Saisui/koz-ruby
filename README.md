# Koz :: 宇宙

造反有理，革命无罪。

一个不中立，人类可达、科技向善的机器人框架。

# 功能

- 插件系统

- 接入 LLM（大语言模型）

- 记忆

- WebUI

# 安装

```
gem install koz
```

# 启动

```
kozbot
```

默认工作目录为 `~/.kozbot`

以当前文件夹为工作目录

```
kozbot -d
```

指定 webui 端口

```
kozbot --port 10100
```

# 安装插件

安装 OneBot 适配器

```
gem install kozbot-snowluma
```
